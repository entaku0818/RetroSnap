## 検索とページ訴求

次回版の日本語サブタイトルは「平成デジカメ・日付入り・白黒・淡色で撮影」。英語は「Y2K Digicam & Date Stamp」。既存のフィルム撮影に、実装済みのデジカメ風撮影を加える。

日本語キーワードは「無料」などの一般語を外し、トイ・光漏れ・ネオン・ヴィンテージ・セピア・粒子・スナップ・Y2Kに絞った。英語では白黒・淡色・粒子など、タイトルとサブタイトルが拾わない特徴を補った。説明の冒頭で無料3台を提示し、有料5台は個別買い切り、プレビューは無料、保存は購入後と明示。

Appleの公式資料にはキーワードを100文字とするページと100 bytesとするページがあるため、今回は両方の制限内に収めた（ja 33文字/79 bytes、en-US 97文字/97 bytes）。名称・サブタイトル30文字、プロモーション170文字、説明4000文字も確認済み。

2026-10-20のiTunes Search APIでは、JP「平成 デジカメ」に平成カメラ、Y2Kカメラ2003、Vinta等、US「y2k camera」にY2K Lab、y2k: 2000s photo editor、Y2K Cam 2003等が返った。カテゴリとして競合が存在することの確認であり、検索量・需要の大きさや端末上の順位を示すものではない。今回のキーワードは実機能との一致を優先した仮説。
