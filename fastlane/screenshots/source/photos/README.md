# スクリーンショットに差し込む写真

`app-store-ja.html` の写真枠が読むファイル。ここにファイルを置くだけで版下に反映される
（HTML 側は触らない）。置いていない枠は、斜線と「何を入れるか」の文字が出る。

## 必要なファイル

| ファイル | 入れるもの | 使われる場所 |
|---|---|---|
| `01-plain70.jpg` | 日常のスナップ（人・街・食べ物など） | 01枚目のライブプレビュー |
| `02-nightneon.jpg` | 夜の街。ネオンや光源が入っているもの | 02枚目のライブプレビュー |
| `03-datestamp98.jpg` | 撮影直後の1枚として見せられるもの | 03枚目 |
| `05-a.jpg` 〜 `05-i.jpg`（9枚） | 一覧に並べるスナップ | 05枚目の写真一覧 |

縦位置（9:19.5 くらい）の写真が枠に一番きれいに収まる。`object-fit: cover` で
中央基準に切られるので、主題は中央寄りのものを選ぶこと。

## 重要

**現像フィルタは版下側で近似的にかけている。** `01-plain70.jpg` などには
「アプリで撮って現像した後の画像」ではなく、**素の写真**を置くこと。
現像済みの画像を置くと二重に効いて、実際のアプリの写りと違う絵になる。

版下の近似（`.film-*` クラス）はあくまで見た目合わせで、`FilmRenderer` の出力そのものではない。
実際の写りに厳密に合わせたいときは、アプリで現像した画像をここに置いたうえで
HTML 側の `.film-*` を外す、という手もある。

## 権利

App Store のスクリーンショットは公開物なので、**権利の所在がはっきりした写真だけ**を使うこと
（自分で撮ったもの、または商用利用可のライセンスが確認できるもの）。
人物が写っているものは肖像の許諾も要る。
